fold is a single Go binary that presents any number of upstream MCP (Model Context Protocol)
servers as one governed virtual server: one endpoint, one policy, one audit trail. It is built
on the official MCP Go SDK on both sides of the proxy, and the official conformance suite runs
through it on every merge.

Before running it against anything that matters:

1. **[Describe your upstreams](/configuration/)** in one config file, validated at load.
2. **[Put a policy in front of them](/security/)** — fold is deny-by-default, and an empty
   allowlist denies everything.
