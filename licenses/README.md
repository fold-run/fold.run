# Third-party licences

## Black Ops One (SIL Open Font License 1.1)

`fold`'s wordmark and favicon are **outlined glyph paths derived from Black Ops
One**, designed by James Grieshaber and Eben Sorkin, retrieved from
github.com/google/fonts. They ship as SVG path data in
`apps/site/src/components/Wordmark.astro`,
`apps/docs/src/assets/wordmark-*.svg`, and the two `favicon.svg` files.

No font binary is redistributed and no derived font is published, so the OFL's
Reserved Font Name clause is not engaged; the licence is kept here for
provenance. Spacing is not the font's own: the wordmark is tracked -70/em with
per-pair kerning (fo -55, ol +10, ld -15). See DESIGN.md section 5.
